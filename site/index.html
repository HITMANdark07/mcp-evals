mcpbench leaderboard

mcpbench runs the same tasks against MCP servers with several models, grades every answer, and records every model call and tool call. Each row below is one cell: one server used by one model across every task and repeat of a suite. For each cell you get task success with a 95% interval, how often the model called tools that do not exist, how much text the server's tool results put into the context, the prompt tokens the provider billed, steps, latency and cost per task. Runs that fail for infrastructure reasons (rate limits, crashes) are retried and reported separately instead of counting against a model. Prompts, limits and tool schemas are identical for every model, and each model is pinned to one provider.

Disclosure: the harness author also wrote NeatCode, one of the servers compared. Tasks, answer keys, graders and every trace are public. See the methodology and the caveats at the bottom of the page.

What the columns mean
Success, 95% CI
Passes / (passes + fails); error runs excluded. Wilson 95% interval in brackets; the bar shows the interval (band) and the point estimate (tick).
Success, errors as fails
Passes / all runs. Read it next to success when a server or provider produced errors.
Invalid tool calls
Share of completed runs that ended because the model called a tool the server does not expose, or sent arguments that are not valid JSON. Such a run is a fail.
Context tokens, median
Tokens of text returned by MCP tool calls per run, counted with o200k_base for every model. Comparable across servers and models; excludes tool schemas.
Provider prompt tokens, median
Prompt tokens reported by the provider, summed over the run's model calls: system prompt, tool schemas and the growing conversation, in each model's own tokenizer. What the run was billed for; not comparable across models.
Steps, latency p50, $/task
Model calls per run; median wall time of the agent loop (setup and indexing excluded); provider-reported cost per run.
Runs
Runs recorded / runs planned for the cell. A cell that did not finish every planned run is marked incomplete.
